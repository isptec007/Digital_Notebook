# Caderneta Digital do Coordenador de Turno

Aplicação web desenvolvida no âmbito da disciplina de Engenharia de Software I, no ISPTEC, para apoiar os coordenadores de turno na gestão de alunos, turmas e ocorrências escolares.

## Objectivo

Centralizar as informações escolares, facilitar o acompanhamento dos alunos e melhorar a organização das ocorrências e das medidas aplicadas.

## Funcionalidades do MVP

- Autenticação por palavra-passe e acesso por perfil.
- Gestão de turmas e alunos.
- Registo de ocorrências com associação de vários alunos.
- Registo das medidas aplicadas.
- Consulta do histórico individual do aluno.
